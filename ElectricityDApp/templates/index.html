🔐 Tamper Simulation

This simulates a hacker secretly changing a block's data WITHOUT recalculating the hash. The chain instantly detects it — this is the core security of blockchain.

📚 How It Works

Each block's hash is calculated from ALL its contents — data, timestamp, nonce, and the previous block's hash.

When you tamper with Block #1's data, its stored hash no longer matches what Python calculates. This mismatch is detected instantly.

Also, Block #2's previous_hash now points to a non-existent hash — breaking the chain link.

Changing any one block breaks every block after it. This is why blockchain cannot be tampered with.
